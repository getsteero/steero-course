    08. Events, dialogs, downloads and popups¶

    In this lesson

    You will learn to:

    • listen to page events with on, once and remove_listener
    • wait for what an action triggers with the expect_* waiters, subscribing before the action
    • accept, dismiss and answer dialogs, and know what steero does without a listener
    • save a download with expect_download and save_as
    • work with popups and several tabs (expect_popup, context.expect_page, browser.pages)

    Time: about 40 minutes. Before this: 07. Network. Code: examples/course/08-events-dialogs-downloads/

    Not everything a page does is a change you can see in the DOM. It writes to the console, throws errors nobody catches, stops to ask the user a question, starts a download, opens another window. A script has to notice these things, and sometimes answer them, or it will miss bugs or get stuck. This lesson uses the Events page (events.html), where each control does one of these things.

    Events¶

    A page (and a context, and the browser) emits events: named notifications with a payload. You subscribe with on(name, handler); the handler is called with the payload every time the event fires.

    page.on("console", lambda message: print(message.type, message.text))
page.on("pageerror", lambda error: print("uncaught:", error))

    The page events you will use most:

    Event Payload Fires when
    console ConsoleMessage (type, text, args) the page calls console.log, error, warn and so on
    pageerror JavaScriptError an exception nobody catches
    dialog Dialog alert, confirm, prompt or a "leave page?" question opens
    download Download the page starts a download
    popup Page the page opens a new tab or window
    request, response, requestfailed Request or Response network traffic (lesson 07)
    load Page the page's load event fires
    close Page the page is closed

    once(name, handler) calls the handler for the next event only. remove_listener(name, handler) stops a handler; pass the same function you registered, so give it a name rather than a lambda when you plan to remove it.

    In the sync API, handlers run on a worker thread, with sync objects, so a handler may call the sync API itself (dialog.accept(), for example). Keep handlers short: record what happened in a list or print it, and make your checks in the main script.

    Coming from Selenium

    Selenium makes you poll for these things: switch_to.alert, the browser log, the window handle list. In steero they arrive as events, the moment they happen, in Chrome and Firefox alike.

    Waiters¶

    A listener collects everything. Often you want just the one event an action causes: the error a click logs, the download a link starts. Each expect_* method is a waiter, used as a with block around the action:

    with page.expect_console_message() as waiter:
    page.get_by_role("button", name="Log a message").click()
print(waiter.value.text)        # Hello from the page

    The waiter starts listening when the block starts and, when the block ends, waits (30 seconds by default) for the event; waiter.value is its payload. The order matters. If you clicked first and started listening afterwards, a fast event could already be over, and the waiter would wait for a second one that never comes. Subscribe before the action is the rule for every waiter.

    The waiters are expect_console_message, expect_dialog, expect_download, expect_popup, expect_request and expect_response, plus the general expect_event(name, predicate), which waits for any event and can filter it:

    with page.expect_event("console", lambda message: message.type == "error") as waiter:
    page.get_by_role("button", name="Log a message").click()   # ignored: not an error
    page.get_by_role("button", name="Log an error").click()
print(waiter.value.text)        # Something went wrong

    All of them take timeout= in seconds.

    Dialogs¶

    alert(), confirm() and prompt() open dialogs, which block the page until someone answers. A script answers with a dialog listener. The listener receives a Dialog with type ("alert", "confirm", "prompt" or "beforeunload"), message and default_value, and must call one of:

    • dialog.accept(): OK. For a prompt, dialog.accept("Ada") types the answer first.
    • dialog.dismiss(): Cancel (or close an alert).
    page.once("dialog", lambda dialog: dialog.accept("Ada"))
page.get_by_role("button", name="Rename").click()
expect(page.get_by_role("status")).to_have_text("Hello, Ada")

    Register the listener before the action that opens the dialog. The click itself does not finish until the dialog is answered, so code after the click is too late.

    Without a listener, steero dismisses every dialog. A stray alert() never hangs a run: an alert is closed, a confirm answers Cancel (false), a prompt answers Cancel (null). That is the safe default, and it means a test that forgot its listener fails on a wrong result ("Item kept") instead of waiting forever.

    expect_dialog() tells you a dialog appeared and what it said, but it cannot answer it: the block ends only after the click, and the click waits for the answer. Use it together with a listener:

    page.once("dialog", lambda dialog: dialog.dismiss())
with page.expect_dialog() as waiter:
    page.get_by_role("button", name="Delete item").click()
print(waiter.value.message)     # Delete the item?

    Coming from Playwright

    The same defaults as Playwright: no listener means dismissed, and a listener must accept or dismiss. In steero's sync API the handler runs on a worker thread, so lambda dialog: dialog.accept() just works.

    Downloads¶

    When a page starts a download (a link to a file the server sends as an attachment, or a link with a download attribute), the browser saves it into the browser profile and fires download. Wait for it with expect_download, then copy the file somewhere with save_as:

    with page.expect_download() as waiter:
    page.get_by_role("link", name="Download the report").click()
download = waiter.value
print(download.suggested_filename)                  # report.csv
saved = download.save_as(Path(folder) / "report.csv")

    save_as waits for the download to finish (60 seconds by default), creates missing folders, and returns the path. Copy the file before the browser closes: the profile, and the original file in it, are deleted then. download.url is where it came from, and download.failure() returns why a download did not complete, or None.

    Save downloads to a temporary folder (the examples use tempfile.TemporaryDirectory()), so a run never leaves files in your repository.

    Popups and tabs¶

    A link with target="_blank" opens a new tab; window.open() opens a new window. To steero both are a new Page and a popup event on the page that opened it. Catch it with expect_popup:

    with page.expect_popup() as waiter:
    page.get_by_role("link", name="Help in a new tab").click()
help_tab = waiter.value
expect(help_tab).to_have_title("Help - steero practice site")
help_tab.close()

    expect_popup hands the popup over once it has committed its URL, so help_tab.url is already the real address. The document may still be loading, though: check it with web-first assertions and locators (which wait), or call help_tab.wait_for_load_state() before a single read such as help_tab.title().

    Two other ways to find pages:

    • context.expect_page() waits for any new page in a context, whichever page or script opened it.
    • browser.pages lists every open page, context.pages those of one context.

    Each page is a separate object, so "switching tabs" is just using the other variable; there is no current tab to switch. page.bring_to_front() makes a tab the active one when that matters for a headed run. Closing a popup (popup.close(), or the page calling window.close()) fires its close event and leaves the other pages untouched.

    Coming from Selenium

    No window_handles and no switch_to.window: the popup is a Page of its own, and the opener keeps working the whole time.

    Async handlers¶

    In the async API, a handler may be a plain function or a coroutine. An async def handler can await the API directly, which is the natural way to answer a dialog:

    async def answer(dialog: steero.Dialog) -> None:
    await dialog.accept("Ada")

page.on("dialog", answer)

    A plain function that needs to call the async API can schedule it instead: page.once("dialog", lambda dialog: asyncio.ensure_future(dialog.accept())). The waiters are async with blocks, and waiter.value is awaited:

    async with page.expect_download() as waiter:
    await page.get_by_role("link", name="Download the report").click()
download = await waiter.value

    Worked example¶

    This script goes through the events page from top to bottom. It prints every console message and uncaught error, answers a confirm and a prompt with one named listener (and removes it afterwards), saves the CSV report to a temporary folder, and opens and closes the help page in a new tab.

    """Lesson 08: handle everything the events page can throw at a script (sync API).

Console messages and an uncaught error, a confirm and a prompt, a download and a new tab.

    python examples/course/serve.py                                      # terminal 1
    python examples/course/08-events-dialogs-downloads/example_events.py # terminal 2

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os
import tempfile
from pathlib import Path

from steero.sync_api import Dialog, expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def answer(dialog: Dialog) -> None:
    """Accept every dialog; give a prompt a name."""
    print(f"Dialog ({dialog.type}): {dialog.message}")
    dialog.accept("Ada" if dialog.type == "prompt" else None)


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        page = browser.new_page()
        page.on("console", lambda message: print(f"Console {message.type}: {message.text}"))
        page.on("pageerror", lambda error: print("Page error:", error))
        page.goto(BASE_URL + "events.html")
        result = page.get_by_role("status")

        # Console messages and an uncaught error arrive as events.
        with page.expect_console_message():
            page.get_by_role("button", name="Log a message").click()
        with page.expect_event("pageerror"):
            page.get_by_role("button", name="Throw an error").click()

        # Dialogs: the listener answers each one while the click waits for it.
        page.on("dialog", answer)
        page.get_by_role("button", name="Delete item").click()
        expect(result).to_have_text("Item deleted")
        page.get_by_role("button", name="Rename").click()
        expect(result).to_have_text("Hello, Ada")
        page.remove_listener("dialog", answer)

        # A download: wait for it, then copy it out of the browser's profile.
        with page.expect_download() as waiter:
            page.get_by_role("link", name="Download the report").click()
        download = waiter.value
        with tempfile.TemporaryDirectory() as folder:
            saved = download.save_as(Path(folder) / download.suggested_filename)
            print(f"Downloaded {download.suggested_filename}: {len(saved.read_text().splitlines())} lines")

        # A link with target=_blank opens a new tab: a popup of this page.
        with page.expect_popup() as waiter:
            page.get_by_role("link", name="Help in a new tab").click()
        help_tab = waiter.value
        expect(help_tab.get_by_role("heading")).to_have_text("Help")
        print("New tab:", help_tab.title(), "| open tabs:", len(browser.pages))
        help_tab.close()
        print("Closed it | open tabs:", len(browser.pages))


if __name__ == "__main__":
    main()

    python examples/course/08-events-dialogs-downloads/example_events.py

    Console log: Hello from the page
Page error: Error: Boom
Dialog (confirm): Delete the item?
Dialog (prompt): What is your name?
Downloaded report.csv: 4 lines
New tab: Help - steero practice site | open tabs: 2
Closed it | open tabs: 1

    The waiters around "Log a message" and "Throw an error" make the script wait for those events before it moves on; their payloads are printed by the listeners.

    Async version

    The same page with the async API: a plain-function console listener next to a coroutine dialog handler, and the waiters as async with blocks.

    """Lesson 08: the events example with the async API.

Handlers may be plain functions or coroutines; an ``async def`` handler can await
``dialog.accept()`` directly.

    python examples/course/08-events-dialogs-downloads/example_events_async.py

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import asyncio
import os
import tempfile
from pathlib import Path

import steero
from steero import expect

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


async def answer(dialog: steero.Dialog) -> None:
    """Accept every dialog; give a prompt a name."""
    print(f"Dialog ({dialog.type}): {dialog.message}")
    await dialog.accept("Ada" if dialog.type == "prompt" else None)


async def main() -> None:
    async with steero.launch(BROWSER, headless=HEADLESS) as browser:
        page = await browser.new_page()
        page.on("console", lambda message: print(f"Console {message.type}: {message.text}"))  # plain function
        page.on("dialog", answer)                                                              # coroutine
        await page.goto(BASE_URL + "events.html")
        result = page.get_by_role("status")

        async with page.expect_console_message() as waiter:
            await page.get_by_role("button", name="Log an error").click()
        print("Waited for:", (await waiter.value).text)

        await page.get_by_role("button", name="Rename").click()
        await expect(result).to_have_text("Hello, Ada")

        async with page.expect_download() as waiter:
            await page.get_by_role("link", name="Download the report").click()
        download = await waiter.value
        with tempfile.TemporaryDirectory() as folder:
            saved = await download.save_as(Path(folder) / download.suggested_filename)
            print("Downloaded", saved.name)

        async with page.expect_popup() as waiter:
            await page.get_by_role("link", name="Help in a new tab").click()
        help_tab = await waiter.value
        await expect(help_tab).to_have_title("Help - steero practice site")
        await help_tab.close()
        print("Opened and closed the help tab")


if __name__ == "__main__":
    asyncio.run(main())

    Exercises¶

    Run each solution from the repository root with the practice site running.

    Exercise 1: no errors allowed¶

    Collect every console error and every uncaught page error into a list. Click Log a message and assert the list is empty. Then click Log an error and Throw an error, and check that both were caught.

    Hint: message.type is "error" for console.error. The events arrive a moment after the click, so use expect.poll(lambda: len(problems)).to_be(2) rather than checking at once.

    Solution 
    """Lesson 08, exercise 1: fail when the page logs a console error or throws an uncaught one.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        page = browser.new_page()
        problems: list[str] = []
        # Register before goto, so errors logged while the page loads are caught too.
        page.on("console", lambda message: problems.append(message.text) if message.type == "error" else None)
        page.on("pageerror", lambda error: problems.append(str(error)))
        page.goto(BASE_URL + "events.html")
        result = page.get_by_role("status")

        page.get_by_role("button", name="Log a message").click()
        expect(result).to_have_text("Logged a message")
        assert problems == [], f"the page reported errors: {problems}"
        print("A plain log message is not a problem")

        page.get_by_role("button", name="Log an error").click()
        page.get_by_role("button", name="Throw an error").click()
        # Events arrive a moment after the click; poll the list instead of sleeping.
        expect.poll(lambda: len(problems)).to_be(2)
        print("Caught:", problems)


if __name__ == "__main__":
    main()

    pageerror and console are separate events: an uncaught exception is not a console message, so a check that only watches the console misses it. In a test suite, register both in a fixture and assert the list is empty at the end of every test.

    Exercise 2: your name, please¶

    Answer the Rename prompt with your name using once, and assert the page greets you. Click Rename again without a listener and check what the page says.

    Solution 
    """Lesson 08, exercise 2: answer a prompt with a name, then see what happens with no listener.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        page = browser.new_page()
        page.goto(BASE_URL + "events.html")
        rename = page.get_by_role("button", name="Rename")
        result = page.get_by_role("status")

        # once(): answer the next dialog only, then the listener is gone.
        page.once("dialog", lambda dialog: dialog.accept("Grace"))
        rename.click()
        expect(result).to_have_text("Hello, Grace")
        print("With a listener:", result.text_content())

        # No listener: steero dismisses the prompt, as if Cancel was pressed.
        rename.click()
        expect(result).to_have_text("No name given")
        print("Without one:", result.text_content())


if __name__ == "__main__":
    main()

    After once has fired, no listener is left, so steero dismisses the second prompt and the page reads null: "No name given".

    Exercise 3: the report¶

    Download the CSV report, save it to a temporary folder, and assert it is called report.csv and has four lines: a header and three products.

    Solution 
    """Lesson 08, exercise 3: download the CSV report and check it has a header and three rows.

The file is saved to a temporary folder, never into the repository.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import csv
import os
import tempfile
from pathlib import Path

from steero.sync_api import launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser, tempfile.TemporaryDirectory() as folder:
        page = browser.new_page()
        page.goto(BASE_URL + "events.html")

        with page.expect_download() as waiter:
            page.get_by_role("link", name="Download the report").click()
        download = waiter.value
        assert download.suggested_filename == "report.csv", download.suggested_filename

        saved = download.save_as(Path(folder) / "report.csv")  # waits for the download to finish
        lines = saved.read_text(encoding="utf-8").splitlines()
        assert len(lines) == 4, lines
        rows = list(csv.DictReader(lines))
        assert [row["name"] for row in rows] == ["Blue mug", "Green teapot", "Red kettle"]
        print(f"{download.suggested_filename}: {len(lines)} lines, header {lines[0]!r}")


if __name__ == "__main__":
    main()

    Exercise 4: the help window¶

    Click Open help window (it calls window.open), check the popup's title and that it knows a script opened it, then click its Close this window button. Wait for the popup to close, and show that the events page still works.

    Hint: popup.expect_event("close") waits for the page to close.

    Solution 
    """Lesson 08, exercise 4: open the help popup window, read it, close it, and carry on.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
Modified: Nov-07-2026 (popups are handed over once their URL commits)
"""

# (the default Chrome backend handles popups since the chromedriver popup repair)

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        page = browser.new_page()
        page.goto(BASE_URL + "events.html")

        with page.expect_popup() as waiter:
            page.get_by_role("button", name="Open help window").click()
        popup = waiter.value
        # The popup has its URL already; assertions wait for the page to finish loading.
        expect(popup).to_have_title("Help - steero practice site")
        expect(popup.get_by_test_id("opener")).to_have_text("a script (window.open)")
        print("Popup heading:", popup.get_by_role("heading").text_content())
        print("Open pages:", len(browser.pages))

        # The page closes itself; the "close" event tells us it is gone.
        with popup.expect_event("close"):
            popup.get_by_role("button", name="Close this window").click()
        print("Popup closed:", popup.is_closed(), "| open pages:", len(browser.pages))

        # Back on the first page, which never stopped working.
        expect(page.get_by_role("status")).to_have_text("Opened help")
        page.get_by_role("button", name="Log a message").click()
        expect(page.get_by_role("status")).to_have_text("Logged a message")
        print("The events page still works")


if __name__ == "__main__":
    main()

    The help page closes itself with window.close(), which only a window opened by a script may do. Afterwards the popup object still answers is_closed() (now True); do not act on it any more.

    Common mistakes¶

    Common mistakes

    • Clicking first and waiting afterwards. page.click(...) and then with page.expect_download(): waits for a second download and fails with no 'download' event within 30 s. Put the action inside the with block.
    • Reading waiter.value inside the with block. The event may not have arrived yet; steero raises the event has not arrived yet; read .value after the 'with' block.
    • Registering the dialog listener after the click. The click waits for the dialog to be answered, and with no listener steero dismisses it, so the page sees Cancel. Register on("dialog") or once("dialog") first.
    • Removing a lambda listener. page.remove_listener("dialog", lambda d: d.accept()) is a new function, so nothing is removed. Keep a reference to the handler, or use once.
    • Checking a list filled by a listener straight after the action. Events arrive a moment later, on another thread. Use a waiter, or expect.poll(...).
    • Reading a popup's title at once. The URL is set, but the page may still be loading. Use expect(popup).to_have_title(...) or a locator, which wait, or popup.wait_for_url("**/help.html") (a glob, as in page.route) or popup.wait_for_load_state().
    • Saving downloads into the working directory. Use a temporary folder. And call save_as before the browser closes: the browser's own copy is deleted with its profile.

    Recap¶

    • on, once and remove_listener subscribe to events such as console, pageerror, dialog, download, popup and close; sync handlers run on a worker thread.
    • Waiters (expect_console_message, expect_dialog, expect_download, expect_popup, expect_event) go around the action, so a fast event is never missed.
    • A dialog listener must accept() or dismiss(); without one, steero dismisses every dialog so nothing hangs.
    • expect_download then download.save_as(path) copies a finished download out of the profile.
    • A popup or new tab is a Page; get it with expect_popup or context.expect_page, and close it when you are done.

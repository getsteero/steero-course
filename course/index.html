    Learn steero¶

    A hands-on course in sixteen lessons, from your first script to a full test suite. Each lesson teaches one part of steero, runs real code against a practice site on your own machine, and ends with exercises you can check yourself.

    Who it is for¶

    Python testers and developers who want to automate Chrome and Firefox: writing end-to-end tests, checking pages before a release, or scripting a browser for a chore. You do not need to know any other browser tool. If you already use Playwright or Selenium, the suggested tracks below skip what you know and point out what is different.

    What you need¶

    • Python 3.11 or newer, and enough Python to write a function and run a script.
    • Chrome or Firefox installed the usual way. Both is better: several lessons compare them.
    • steero installed in a virtual environment. Every lesson shows its example script in full, so you can copy the code from the page.
    • A terminal and an editor. Lessons show PowerShell and bash where the commands differ.

    How the course works¶

    Every lesson follows the same pattern:

    1. Read the concepts. Each one comes with a short snippet.
    2. Run the worked example from examples/course/NN-topic/. Change it and run it again.
    3. Do the exercises. Each has a collapsed solution: try first, then open it and compare.
    4. Check the common mistakes box before you move on. It lists the errors people actually hit.

    Boxes marked Coming from Playwright, Coming from Selenium and Browser support are there for the readers who need them; skip them if they do not apply to you. Conventions explains every box, and how the examples are written.

    Every example and solution in the course is run by steero's own test suite in Chrome and Firefox, so the code you see is code that works.

    The practice site¶

    The lessons drive a small site served from your machine, so nothing depends on the internet and nothing you do can affect a real service. Start it in its own terminal and leave it running:

    python examples/course/serve.py

    Practice site: http://127.0.0.1:8765/
Press Ctrl+C to stop.

    Open that address in your browser to look around. Then run an example from a second terminal:

    python examples/course/01-getting-started/example_first_script.py

    The examples read three environment variables, so you can change what they do without editing them:

    Variable Default Meaning
    STEERO_COURSE_URL http://127.0.0.1:8765/ Where the practice site is. Set it if you used --port.
    STEERO_COURSE_BROWSER chrome chrome, firefox or edge.
    STEERO_COURSE_HEADED not set 1 shows the browser window.

    Lessons¶

    # Lesson What you learn Time
    01 Getting started Install, check your browsers, first script (sync and async), headed and headless, screenshots, reading a failure 30 min
    02 Locators Finding elements by role, label, text and test id; chaining and filters; frames and shadow DOM; strictness 45 min
    03 Actions and auto-waiting Clicking, typing and forms; what actionability checks; timeouts in seconds; files and drag and drop 45 min
    04 Assertions Web-first expect, negation, soft assertions, expect.poll, ARIA snapshots 40 min
    05 Visual testing to_have_screenshot, baselines, masks and tolerance, updating snapshots 30 min
    06 Contexts and emulation Isolated contexts, devices, locale and time zone, geolocation and permissions, logging in once with storage state 45 min
    07 Network Watching requests, routing, mocking, changing real responses, HTTP auth, the API request context 60 min
    08 Events, dialogs, downloads and popups Page events, waiting for what an action triggers, dialogs, downloads, new tabs 40 min
    09 The pytest plugin Fixtures, options, several browsers, failure artifacts, base URL 45 min
    10 Debugging Tracing and steero show-trace, video, pause(), headed runs, reading errors 40 min
    11 Recording with codegen steero codegen, the toolbar, how locators are chosen, cleaning up a recording 25 min
    12 Self-healing locators Fingerprints and baselines, when healing refuses, fixing the test, strict mode 35 min
    13 Browsers and backends Chrome extras over CDP, Firefox specifics, Edge and channels, pinned browser versions 35 min
    14 AI agents with MCP steero mcp, connecting a client, the tools, safety 25 min
    15 Migrating from Playwright The compatibility layer first, then moving to native steero 40 min
    16 Capstone: a ControlLab suite A complete test suite for a real app, with a local gate 90 min

    The whole course takes about eleven hours. Lessons 01 to 04 are the core; after them, take the others in any order that suits your work.

    Suggested tracks¶

    New to browser automation. Take the course in order, and leave the specialist lessons for when you need them:

    01, 02, 03, 04, 06, 07, 08, 09, 10, 05, 11, 12, 16. Later, as needed: 13, 14.

    Coming from Playwright. Most of the API will look familiar. Learn what differs (seconds, stock browsers, the pytest fixture names), then go straight to the tools:

    01, 15, 03, 04, 09, 10, 13, 12, 16. Skim 02, 06, 07 and 08 for their "Coming from Playwright" boxes.

    Coming from Selenium. The biggest change is that you stop writing waits. Spend your time on locators, actions and assertions, then on the parts Selenium does not have:

    01, 02, 03, 04, 06, 07, 08, 09, 10, 12, 13, 16. See also Migrating from Selenium.

    Ready? Start with 01. Getting started.

    15. Migrating from Playwright¶

    In this lesson

    You will learn to:

    • run an existing Playwright for Python script on steero by changing only the import
    • keep pytest-playwright fixture names with -p steero.compat.playwright.pytest
    • know what the compatibility layer translates (milliseconds, wait_until, selector shortcuts) and what raises UnsupportedFeature
    • move code to steero's native API step by step: seconds, steero.launch, locators, steero_page
    • decide when to stay on the layer and when to move

    Time: about 40 minutes. Before this: 14. AI agents with MCP. Code: examples/course/15-migrating-from-playwright/

    If you have Playwright scripts or a pytest-playwright suite already, you do not have to rewrite them before trying steero. A compatibility layer accepts Playwright's API, translates it, and runs it on stock Chrome and Firefox. This lesson shows what that layer does, where it stops, and how to move to steero's own API when you are ready.

    Milliseconds in this lesson

    Everywhere else in the course, timeouts are seconds. Code that imports from steero.compat.playwright keeps Playwright's milliseconds: timeout=2000 there is two seconds. Each snippet below says which API it uses.

    Change only the import¶

    The layer lives in steero.compat.playwright, with the same module names as Playwright:

    # before
from playwright.sync_api import sync_playwright, expect
# after
from steero.compat.playwright.sync_api import sync_playwright, expect

    The async API is steero.compat.playwright.async_api (async_playwright). Everything after the import stays as it was: sync_playwright() starts the layer, p.chromium launches stock Chrome, p.firefox launches stock Firefox, p.chromium.launch(channel="msedge") launches Edge. p.webkit exists, but launching it raises, because Safari has no WebDriver BiDi. The layer never imports the real playwright package, so you can install both side by side and switch one import at a time.

    What is translated¶

    The layer turns Playwright's conventions into steero calls:

    Playwright writes The layer does
    timeout=2000, set_default_timeout(10000), slow_mo=50, expect(..., timeout=3000) divides by 1000: steero gets seconds. timeout=0 means no limit, as in Playwright
    wait_until="load", "domcontentloaded", "commit", "networkidle" steero's complete, interactive, none; networkidle waits for 500 ms with no requests
    response = page.goto(url) returns the main Response (.ok, .status, .json())
    page.click(selector), fill, text_content, is_visible, query_selector ... builds a locator for the first match and acts on it
    evaluate_handle, query_selector, element_handle(), JSHandle, ElementHandle steero's JS and element handles (Handles guide)
    route.fulfill(json=...), route.abort(), handlers taking (route) or (route, request) steero's routing
    expect_response, expect_request, expect_download, expect_console_message ... steero's event waiters, with predicate=
    Error, TimeoutError steero.SteeroError, steero.SteeroTimeoutError

    The migration guide has the complete list.

    What is not¶

    Anything Playwright has and steero does not raises UnsupportedFeature, from steero.compat.playwright. Its message names the missing piece and links the guide, and its feature attribute holds the name:

    from steero.compat.playwright import UnsupportedFeature

try:
    p.chromium.launch_persistent_context("profile")
except UnsupportedFeature as error:
    print(error.feature)   # BrowserType.launch_persistent_context

    The main ones: WebKit, launch_persistent_context (steero always starts from a fresh profile), connect and connect_over_cdp, route(times=), goto(referer=), and a few launch options (env=, ignore_default_args=, downloads_path=). An argument steero lacks is dropped silently only when it holds Playwright's do-nothing value (None, False, 0); any other value raises, so click(trial=True) never quietly clicks. UnsupportedFeature is a NotImplementedError; for a missing attribute it is also an AttributeError, so hasattr(page, "request_gc") keeps working.

    Browser support

    The layer runs on everything steero drives: Chrome (both backends), Edge and Firefox. A Playwright option that maps to a Chrome-only steero option (for example is_mobile in new_context) raises UnsupportedOnBrowser in Firefox, exactly as in native steero (lesson 13).

    pytest-playwright suites¶

    pytest-playwright gives tests fixtures called page, context, browser, browser_name and base_url. steero has an opt-in plugin with the same names and markers:

    pytest -p steero.compat.playwright.pytest --browser chromium --browser firefox

    Or put -p steero.compat.playwright.pytest in the suite's addopts, as the lesson's pw_suite/pytest.ini does. It provides page, context, new_context, browser, browser_name (chromium or firefox; Edge counts as chromium), browser_type, browser_context_args, base_url, output_path, is_chromium, is_firefox and the skip_browser, only_browser and browser_context_args markers. The objects come from the compatibility layer, so the tests keep their milliseconds.

    It is not on by default: its fixture names would clash with pytest-playwright's when both are installed. For the same reason, the plain options (--browser, --base-url, --headed, --screenshot, --tracing ...) are registered only when pytest-playwright is not installed; the --steero- spellings (--steero-browser, --steero-base-url ...) always work, and the lesson's script uses those.

    Moving to native steero¶

    The layer is a bridge, not a destination: it adds a translation step to every call, and new steero features (self-healing, the Chrome extras, steero's own fixtures) are native only. Move a script or a test module at a time:

    1. Imports and launch. from steero.sync_api import expect, launch, then with launch("chrome") as browser: instead of sync_playwright() and p.chromium.launch().
    2. Timeouts. Divide every number by 1000: timeout=2000 becomes timeout=2. Search the file for timeout, delay, slow_mo and wait_for_timeout.
    3. Navigation. wait_until="domcontentloaded" becomes "interactive", "load" becomes "complete", "commit" becomes "none". Native goto() returns the main Response, as in Playwright (None for about:blank and other pages without one), so page.goto(url).status carries over unchanged.
    4. Selector shortcuts to locators. page.fill("#username", "ada") becomes page.get_by_label("User name").fill("ada"): the same action, a locator that says what the user sees (lesson 02).
    5. Tests. Use the native plugin's steero_page fixture (or alias it as page in conftest.py, lesson 09), and drop -p steero.compat.playwright.pytest.

    The migration guide's table maps the remaining names.

    Coming from Selenium

    There is no compatibility layer for Selenium: its model (element references, explicit waits) is too different for a faithful translation. The Selenium guide maps the concepts; the native API in this course is the target.

    Choosing¶

    Stay on the layer while you evaluate, or when a large suite must keep running during a gradual move. Move to native steero for new code, and for anything that should use self-healing, MCP or the Chrome extras.

    Choose steero when you need the stock browsers your users run (especially Firefox, which Playwright patches), the W3C standard protocol, or the built-in healing and MCP server. Stay with Playwright when you need WebKit, persistent profiles, clients in other languages, or the maturity of a tool with years of use and a large team behind it. The comparison page says more.

    Worked example¶

    The first script is written as Playwright's documentation would write it (sync API, milliseconds, page.fill(selector), expect_response, route.fulfill(json=...)), with only the import changed. It signs in, waits for the products API and then mocks it.

    """Lesson 15: a Playwright for Python script, run on steero by changing only the import.

Everything below the import is written the way Playwright's documentation writes it:
``sync_playwright()``, ``p.chromium``, selector shortcuts such as ``page.fill(selector)``,
``wait_until=``, ``route.fulfill(json=...)``, ``expect_response`` and timeouts in
MILLISECONDS, which the compatibility layer translates.

    python examples/course/15-migrating-from-playwright/example_playwright_script.py

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

# from playwright.sync_api import expect, sync_playwright      # before
from steero.compat.playwright.sync_api import expect, sync_playwright  # after

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"

MOCKED = [{"id": 7, "name": "Mocked mug", "price": 1.0, "stock": 5}]


def main() -> None:
    with sync_playwright() as p:
        browser_type = p.firefox if BROWSER == "firefox" else p.chromium
        channel = "msedge" if BROWSER == "edge" else None
        browser = browser_type.launch(headless=HEADLESS, channel=channel, timeout=30000)  # 30000 ms
        page = browser.new_page()
        page.set_default_timeout(10000)  # 10 seconds, in Playwright's milliseconds

        response = page.goto(BASE_URL + "login.html", wait_until="domcontentloaded")
        assert response is not None and response.ok
        page.fill("#username", "ada")
        page.fill("#password", "lovelace")
        page.click("#sign-in")
        expect(page.locator("#status")).to_have_text("Welcome, ada", timeout=2000)  # 2 seconds
        print("Signed in:", page.text_content("#status"))

        with page.expect_response("**/api/products") as response_info:
            page.goto(BASE_URL + "products.html")
        print("Products API answered", response_info.value.status)

        page.route("**/api/products", lambda route: route.fulfill(json=MOCKED))
        page.click("#reload")
        expect(page.get_by_role("status")).to_have_text("1 products")
        print("Mocked:", page.text_content("tbody td"))
        browser.close()


if __name__ == "__main__":
    main()

Compare it line by line with ``example_playwright_script.py``: no ``sync_playwright()``,

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")

HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"

MOCKED = [{"id": 7, "name": "Mocked mug", "price": 1.0, "stock": 5}]


def main() -> None:
    with launch(BROWSER, headless=HEADLESS, timeout=30) as browser:  # 30 seconds
        page = browser.new_page()
        page.set_default_timeout(10)  # 10 seconds

        # "interactive" is steero's spelling of Playwright's "domcontentloaded".

        page.get_by_label("Password").fill("lovelace")
        page.get_by_role("button", name="Sign in").click()

        print("Signed in:", page.get_by_role("status").text_content())

        with page.expect_response("**/api/products") as response_info:
            page.goto(BASE_URL + "products.html")
        print("Products API answered", response_info.value.status)

        page.route("**/api/products", lambda route: route.fulfill(json=MOCKED))
        page.get_by_role("button", name="Reload").click()
        expect(page.get_by_role("status")).to_have_text("1 products")
        print("Mocked:", page.get_by_role("cell").first.text_content())


if __name__ == "__main__":
    main()

    Exercise 2: the one call that cannot move¶

    This ported script stops with UnsupportedFeature. Find the call, read what the error names, and replace it with something steero supports. The script mocks the products API for the first reload only; the second reload should show the real products again.

    page.goto("http://127.0.0.1:8765/products.html")
expect(page.get_by_role("status")).to_have_text("3 products")
page.route("**/api/products", lambda route: route.fulfill(json=MOCKED), times=1)
page.click("#reload")
expect(page.get_by_role("status")).to_have_text("1 products")
page.click("#reload")
expect(page.get_by_role("status")).to_have_text("3 products")
    Solution 
    """Lesson 15, exercise 2: find the call that raises UnsupportedFeature, and replace it.

The ported script mocked the products API for one request only, with
``page.route(url, handler, times=1)``. steero's routing has no ``times=``, so the layer raises
``UnsupportedFeature`` naming the argument. The script shows that error once, then does the same
job with a handler that mocks the first request and lets the later ones through.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
Modified: Nov-07-2026 (evaluate_handle is supported now: the exercise uses route(times=) instead)
"""

import os

from steero.compat.playwright import UnsupportedFeature
from steero.compat.playwright.sync_api import Route, expect, sync_playwright

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"

MOCKED = [{"id": 7, "name": "Mocked mug", "price": 1.0, "stock": 5}]


def main() -> None:
    with sync_playwright() as p:
        browser_type = p.firefox if BROWSER == "firefox" else p.chromium
        channel = "msedge" if BROWSER == "edge" else None
        browser = browser_type.launch(headless=HEADLESS, channel=channel)
        page = browser.new_page()
        page.goto(BASE_URL + "products.html")
        expect(page.get_by_role("status")).to_have_text("3 products")  # the page's own request is done

        try:  # the original line
            page.route("**/api/products", lambda route: route.fulfill(json=MOCKED), times=1)
        except UnsupportedFeature as error:
            print("Unsupported:", error.feature)

        # The replacement: mock the first request, then let every later one reach the server.
        mocked: list[str] = []

        def first_only(route: Route) -> None:
            if mocked:
                route.continue_()
                return
            mocked.append(route.request.url)
            route.fulfill(json=MOCKED)

        page.route("**/api/products", first_only)
        page.click("#reload")
        expect(page.get_by_role("status")).to_have_text("1 products")
        print("First reload:", page.text_content("tbody td"))
        page.click("#reload")
        expect(page.get_by_role("status")).to_have_text("3 products")
        print("Second reload:", page.text_content("tbody td"))
        assert len(mocked) == 1
        browser.close()


if __name__ == "__main__":
    main()

    Unsupported: Page.route(times=...)
First reload: Mocked mug
Second reload: Blue mug

    steero's routing has no times=, so the layer refuses the argument rather than mocking every request. A handler that keeps its own count does the same job: it fulfills the first request and lets the later ones through with route.continue_(). The solution catches the error only to show its feature; in your own port, just change the line.

    """Lesson 15, exercise 3: the compatibility script from the lesson rewritten to native steero.

Every millisecond timeout became seconds (``10000`` is ``10``, ``2000`` is ``2``, ``500`` is
``0.5``), ``wait_until`` uses steero's values, and selector shortcuts became locators.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026

Native page.wait_for_selector() would also work; it returns a locator, where the layer returns an element handle.

    Common mistakes¶

    Common mistakes

    • Moving a line to native steero and keeping its milliseconds. click(timeout=5000) in native code waits 83 minutes instead of five seconds. Convert the numbers in the same edit.
    • Mixing the layer's objects with native ones. A compat page passed to native steero.sync_api.expect raises a TypeError (currently with a confusing message such as "this assertion needs a page, not a locator"), and the reverse fails too. Import expect from the same API as the page, and move a whole script or module at a time.
    • wait_until="domcontentloaded" in native code. The browser rejects it with ProtocolError: browsingContext.navigate: invalid argument .... Native steero spells it "interactive" (and "load" is "complete").
    • page.goto(...).ok on about:blank or a data: URL. There is no network response, so goto() returns None there, in steero as in Playwright. Check for None first.
    • Expecting the plugin without -p. Without -p steero.compat.playwright.pytest (or the addopts line), pytest reports fixture 'page' not found.
    • --browser firefox is "unrecognized". pytest-playwright is installed and owns the plain options. Use --steero-browser firefox (and --steero-base-url and so on).
    • Catching UnsupportedFeature to keep a test green. The feature still does nothing. Replace the call; the error's feature tells you which one.

    Recap¶

    • from steero.compat.playwright.sync_api import ... runs Playwright code unchanged on stock Chrome, Edge and Firefox, with timeouts in milliseconds.
    • -p steero.compat.playwright.pytest keeps pytest-playwright's page and friends; it is opt-in so it never clashes with the real plugin.
    • What steero cannot do raises UnsupportedFeature naming the feature.
    • Moving to native: launch(), seconds, interactive/complete, locators, steero_page.
    • Use the layer to start quickly; write new code natively.

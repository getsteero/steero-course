    01. Getting started¶

    In this lesson

    You will learn to:

    • install steero and check which browsers it can find with steero doctor
    • prepare drivers ahead of time with steero install
    • write and run a first script with the sync API, and the same script with the async API
    • switch between headless and headed runs
    • save screenshots of the viewport, the full page and a single element
    • recognise the errors a first script usually hits, and fix them

    Time: about 30 minutes. Before this: nothing; this is the first lesson. Code: examples/course/01-getting-started/

    By the end of this lesson you will have driven a real Chrome or Firefox from Python: opened a page, filled in a form, checked the result and saved a picture of it. Every later lesson builds on the script you write here.

    Install steero¶

    steero is a Python package with one dependency (websockets). It drives the Chrome and Firefox already installed on your machine, so there is no browser to download.

    Work in a virtual environment inside your copy of the repository:

    python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e . pytest

    python -m venv .venv
source .venv/bin/activate
pip install -e . pytest

    pip install -e . installs the steero in this checkout, so the library and the course examples always match. (In your own projects, pip install steero is all you need.) Installing steero also installs the steero command:

    steero --version

    steero 1.0.0rc3

    Check your browsers¶

    steero doctor reports what steero can find on this machine:

    steero doctor

    steero 1.0.0rc3 (Python 3.13.5, win32)
cache: C:\Users\you\AppData\Local\steero
  chrome   157.0.8103.38    C:\Program Files\Google\Chrome\Application\chrome.exe
  firefox  found            C:\Program Files\Mozilla Firefox\firefox.exe
  edge     157.0.4341.42    C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
  chromedriver cached: none (downloaded on first Chrome launch)

    You need at least one of Chrome and Firefox. If one says missing, install it the normal way, or point steero at a browser in an unusual place with STEERO_CHROME_PATH or STEERO_FIREFOX_PATH. The cache is where steero keeps the drivers it downloads and the pinned browser versions you install in lesson 13.

    Browser support

    Both browsers are driven over WebDriver BiDi, the W3C standard protocol, so the same script works in each. They are reached differently:

    • Firefox speaks BiDi itself. Nothing extra is needed.
    • Chrome is reached through chromedriver, which must match the Chrome version. steero downloads the right one from Chrome for Testing the first time you launch Chrome, and caches it. Lesson 13 shows a second way, backend="chromium-bidi", with no driver.
    • Edge works like Chrome, with msedgedriver.

    Prepare drivers ahead of time¶

    The first Chrome launch pauses for a few seconds while chromedriver downloads. To do that step now (for example before going offline, or when setting up a build machine), run:

    steero install chromedriver

    chromedriver for Chrome 157.0.8103.38: C:\Users\you\AppData\Local\steero\drivers\chromedriver-157.0.8103.38\chromedriver.exe

    steero install also fetches the chromium-bidi mapper (steero install chromium-bidi) and pinned browsers such as steero install chrome@154; lesson 13 covers both.

    Start the practice site¶

    Every lesson runs against a small site served from your own machine. Open a second terminal, activate the same virtual environment, and start it:

    python examples/course/serve.py

    Practice site: http://127.0.0.1:8765/
Press Ctrl+C to stop.

    Leave it running for the rest of the course. Open http://127.0.0.1:8765/login.html in your own browser and sign in once by hand: any user name works, the password must not be empty, and the welcome message appears about half a second after you click. Your first script will do exactly this.

    Your first script¶

    Here is the whole script. Read it once, then we will go through it.

    """Lesson 01: a first steero script (sync API).

Opens the practice site, signs in, checks the welcome message and saves a screenshot.

    python examples/course/serve.py                                   # terminal 1
    python examples/course/01-getting-started/example_first_script.py # terminal 2

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        print(f"Running {browser.name} {browser.version}")
        page = browser.new_page()

        page.goto(BASE_URL + "login.html")
        print("Title:", page.title())

        page.get_by_label("User name").fill("ada")
        page.get_by_label("Password").fill("lovelace")
        page.get_by_role("button", name="Sign in").click()

        # expect() keeps checking until the text appears (up to 5 seconds), so no sleep is needed.
        expect(page.get_by_role("status")).to_have_text("Welcome, ada")

        page.screenshot("signed-in.png")
        print("Saved signed-in.png")


if __name__ == "__main__":
    main()

    Run it from the repository root, in the terminal that is not running the server:

    python examples/course/01-getting-started/example_first_script.py

    Running chrome 157.0.8103.38
Title: Sign in - steero practice site
Saved signed-in.png

    Open signed-in.png: it shows the form with "Welcome, ada" under the button. Nothing else happened on screen, because the browser ran headless (without a window). Here is what each part does.

    The three settings. BASE_URL, BROWSER and HEADLESS come from environment variables, with defaults that suit the practice site. Every example in the course starts this way, so you can switch browser without editing code:

    $env:STEERO_COURSE_BROWSER = "firefox"
python examples/course/01-getting-started/example_first_script.py

    STEERO_COURSE_BROWSER=firefox python examples/course/01-getting-started/example_first_script.py

    launch(BROWSER, headless=HEADLESS) starts the browser with a fresh, empty profile and returns a Browser. Used in a with block, it is closed when the block ends, even if something inside fails: the browser process exits and its temporary profile is deleted. Always launch this way (or call browser.close() in a finally), and a script never leaves a browser running behind it.

    browser.new_page() opens a tab. page.goto(url) loads a URL and returns once the page's load event has fired.

    page.get_by_label("User name") is a locator: a description of how to find an element, here "the control whose label is User name". Building it does not touch the page. Only an action, such as .fill("ada"), finds the element, and it looks again every time. Lesson 02 is all about locators. For now, notice that the script finds things the way a person would describe them (the field labelled "User name", the button called "Sign in") rather than by an id or a CSS class, which change more often than the words on the screen.

    .click() waits until the button can be clicked (it exists, is visible, is enabled, is not moving and is not covered by something else) and then clicks it with real mouse events. This is auto-waiting, and it is why the script has no sleep() calls. Lesson 03 explains each check.

    expect(page.get_by_role("status")).to_have_text("Welcome, ada") is a web-first assertion: it keeps checking until the text matches or 5 seconds pass. The message appears half a second after the click, and the assertion simply waits for it. If it never appears, the assertion fails with an error saying what it saw instead. Lesson 04 covers assertions.

    page.screenshot("signed-in.png") saves a PNG of what is visible in the page.

    Coming from Playwright

    This will look familiar: the locator, action and expect APIs follow Playwright's names. Three things differ. There is no sync_playwright() object to start first: launch("chrome") or launch("firefox") is the whole setup. The browsers are the stock Chrome and Firefox you have installed, not patched builds. And every timeout is in seconds, so timeout=5 is five seconds, not five milliseconds. Lesson 15 shows how to run existing Playwright code unchanged.

    Coming from Selenium

    There is no driver to download or start yourself, and no WebDriverWait: actions and assertions wait on their own. A locator is not an element you found earlier, so there is no "stale element" error; it finds the element again on every use.

    The same script, async¶

    steero is built on asyncio, and the sync API you just used is a thin layer over it. If your program is already async (a web service, a bot, a tool that drives many pages at once), use the async API directly:

    """Lesson 01: the same first script, written with the async API.

    python examples/course/01-getting-started/example_first_script_async.py

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import asyncio
import os

import steero
from steero import expect

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


async def main() -> None:
    async with steero.launch(BROWSER, headless=HEADLESS) as browser:
        print(f"Running {browser.name} {browser.version}")
        page = await browser.new_page()

        await page.goto(BASE_URL + "login.html")
        print("Title:", await page.title())

        await page.get_by_label("User name").fill("ada")
        await page.get_by_label("Password").fill("lovelace")
        await page.get_by_role("button", name="Sign in").click()

        await expect(page.get_by_role("status")).to_have_text("Welcome, ada")

        await page.screenshot("signed-in-async.png")
        print("Saved signed-in-async.png")


if __name__ == "__main__":
    asyncio.run(main())

    The differences are mechanical:

    Sync Async
    from steero.sync_api import expect, launch import steero and from steero import expect
    with launch(...) as browser: async with steero.launch(...) as browser:
    page.goto(...) await page.goto(...)
    expect(...).to_have_text(...) await expect(...).to_have_text(...)
    run with main() run with asyncio.run(main())

    Building a locator never needs await (it does not touch the page); actions, reads and assertions do. The course uses the sync API first, because most tests and scripts are easier to read without await on every line, and shows async wherever the difference matters.

    How the sync API works: each sync Browser runs its own event loop on a background thread, and each call waits for its result. Pick one API per program and stay with it; do not pass objects from one to the other.

    Headless and headed¶

    Browsers launch headless by default: no window, which is faster and works on machines with no screen, such as a build server. While you are writing a script, it often helps to watch it. Launch headed with headless=False, or, for the course examples, set STEERO_COURSE_HEADED:

    $env:STEERO_COURSE_HEADED = "1"
python examples/course/01-getting-started/example_first_script.py
Remove-Item Env:STEERO_COURSE_HEADED

    STEERO_COURSE_HEADED=1 python examples/course/01-getting-started/example_first_script.py

    A window opens, the form fills in, and the window closes when the script ends. It runs as fast as it can, so it is over quickly; launch("chrome", headless=False, slow_mo=0.5) waits half a second before each action so you can follow it. Lesson 10 shows how to stop at a point with page.pause() and look around.

    launch() takes a few other options you will meet later. The ones worth knowing now:

    Option Default Meaning
    headless True False shows the window
    window_size (1280, 800) the initial window size
    timeout 30 seconds allowed for the browser to start
    ignore_https_errors False accept self-signed certificates
    executable_path discovered use a specific browser binary

    Screenshots¶

    page.screenshot() takes a picture of the viewport (what fits in the window). Two variations cover most needs: full_page=True for the whole scrollable page, and locator.screenshot() for a single element.

    """Lesson 01: three kinds of screenshot (viewport, full page, one element).

    python examples/course/01-getting-started/example_screenshots.py

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero.sync_api import launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    # window_size sets the browser window; the screenshot is of the page area inside it.
    with launch(BROWSER, headless=HEADLESS, window_size=(1024, 700)) as browser:
        page = browser.new_page()
        page.goto(BASE_URL)

        page.screenshot("home-viewport.png")                  # what fits in the window
        page.screenshot("home-full.png", full_page=True)      # the whole scrollable page
        png = page.locator("table").screenshot("endpoints.png")  # just one element

        # Every screenshot call also returns the PNG bytes, handy for attaching to a report.
        print(f"Saved 3 screenshots; the table alone is {len(png):,} bytes")


if __name__ == "__main__":
    main()

    Each call writes the file when you give it a path, and also returns the PNG as bytes, which is handy when you want to attach the picture to a report instead of saving it. Comparing screenshots against a saved baseline is a different job, covered in lesson 05.

    Where things go wrong¶

    Most first scripts fail for one of a handful of reasons, and steero's errors say which. It is worth seeing one on purpose. This script asks for a button that does not exist, with a timeout of 2 seconds:

    """Lesson 01: what a failure looks like, so the first real one is not a surprise.

The script looks for a button that does not exist, with a short timeout, and prints the error.

    python examples/course/01-getting-started/example_when_it_fails.py

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero import SteeroTimeoutError
from steero.sync_api import launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        page = browser.new_page()
        page.goto(BASE_URL + "login.html")
        try:
            # Timeouts are in seconds: this waits up to 2 seconds for a button called "Log in".
            page.get_by_role("button", name="Log in").click(timeout=2)
        except SteeroTimeoutError as error:
            print("The click timed out, as expected:")
            print("   ", error)


if __name__ == "__main__":
    main()

    The click timed out, as expected:
    click get_by_role('button', name='Log in'): timed out after 2 s: no element matches

    The message names the action, the locator, the time it waited, and the last thing that was wrong. "No element matches" means the locator found nothing: here the button is called "Sign in", not "Log in". Other endings point elsewhere, for example "element is not visible" or "element is covered by <div#overlay>". Lesson 03 lists them all.

    The table below is the list to come back to when a script will not run:

    What you see What it means What to do
    LaunchError: ... not found or STEERO_CHROME_PATH points at ..., which does not exist steero cannot find the browser Run steero doctor; install the browser or fix the path variable
    LaunchError: download failed: ... on the first Chrome launch the chromedriver download failed (offline, proxy, firewall) Run steero install chromedriver where you have access, or use Firefox
    ProtocolError: browsingContext.navigate: unknown error: net::ERR_CONNECTION_REFUSED nothing is listening at that URL Start the practice site; check STEERO_COURSE_URL matches its port
    SteeroTimeoutError: ... timed out after 10 s: no element matches the locator finds nothing Check the text, role or label against the page (open it headed)
    StrictModeViolation: get_by_role('button') matched 2 elements the locator is ambiguous, so steero refuses to guess Make the locator more specific; lesson 02 shows how
    RuntimeWarning: coroutine ... was never awaited an async call is missing await Add await; in sync code, import from steero.sync_api
    AttributeError: 'coroutine' object has no attribute ... the same: a missing await on a call whose result you used Add await before the call

    Exercises¶

    Run each solution from the repository root with the practice site running, the same way as the examples.

    Exercise 1: an empty password¶

    Write a script that enters a user name, leaves the password empty and clicks Sign in. Check that the page shows "Password is required" and that the welcome message did not appear.

    Hint: page.get_by_text("Password is required") finds the error, and to_be_visible() checks that it is shown.

    Solution 
    """Lesson 01, exercise 1: sign in without a password and check the error message.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


def main() -> None:
    with launch(BROWSER, headless=HEADLESS) as browser:
        page = browser.new_page()
        page.goto(BASE_URL + "login.html")
        page.get_by_label("User name").fill("ada")
        page.get_by_role("button", name="Sign in").click()
        expect(page.get_by_text("Password is required")).to_be_visible()
        expect(page.get_by_role("status")).to_have_text("")
        print("The form refused an empty password")


if __name__ == "__main__":
    main()

    to_have_text("") on the status line confirms that no welcome message appeared. It passes at once here, because the form never starts signing in.

    Exercise 2: just the form¶

    Sign in as grace (any password), but before clicking Sign in, save a screenshot of only the form, as form.png. After the welcome message appears, save a full-page screenshot as welcome-full.png. Open both files and check they show what you expect.

    Hint: the form has the id login, so page.locator("#login") finds it. Lesson 02 shows better ways.

    Solution 
    """Lesson 01, exercise 2: screenshot only the filled-in form, then the whole page after signing in.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import os

from steero.sync_api import expect, launch

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")

        print("Saved form.png and welcome-full.png")

    Exercise 3: async, and the page title¶

    Write an async script that prints the page title, signs in, and then checks that the title changed to "Welcome - steero practice site". Print the title again at the end.

    Hint: expect(page).to_have_title(...) is an assertion about the page rather than a locator, and it waits like the others.

    Solution 
    """Lesson 01, exercise 3: in async code, sign in and check that the page title changed.

Author: Pandiyaraj Karuppasamy
Date: Nov-07-2026
"""

import asyncio
import os

import steero
from steero import expect

BASE_URL = os.environ.get("STEERO_COURSE_URL", "http://127.0.0.1:8765/")
BROWSER = os.environ.get("STEERO_COURSE_BROWSER", "chrome")
HEADLESS = os.environ.get("STEERO_COURSE_HEADED") != "1"


async def main() -> None:
    async with steero.launch(BROWSER, headless=HEADLESS) as browser:
        page = await browser.new_page()
        await page.goto(BASE_URL + "login.html")
        print("Before:", await page.title())

        await page.get_by_label("User name").fill("ada")
        await page.get_by_label("Password").fill("lovelace")
        await page.get_by_role("button", name="Sign in").click()

        # The title changes half a second after the click; to_have_title waits for it.
        await expect(page).to_have_title("Welcome - steero practice site")
        print("After: ", await page.title())


if __name__ == "__main__":
    asyncio.run(main())

    If you printed await page.title() straight after the click instead of asserting first, you probably saw the old title: the page changes it half a second later. The assertion waits; a plain read does not.

    Exercise 4: both browsers¶

    If you have both Chrome and Firefox, run example_first_script.py in each by setting STEERO_COURSE_BROWSER. Compare the two screenshots: the layout is the same, the fonts are drawn slightly differently. This is why lesson 05 keeps a separate visual baseline per browser.

    Common mistakes¶

    Common mistakes

    • Running an example before starting the practice site. The script fails with net::ERR_CONNECTION_REFUSED. Start python examples/course/serve.py in another terminal.
    • Starting the server on another port and forgetting to say so. If you used --port, set STEERO_COURSE_URL to the address it printed.
    • Adding time.sleep() to wait for the page. The script gets slower and still fails on a slow day. Use an expect(...) assertion for the thing you are waiting for.
    • Reading a value straight after an action and getting the old one. page.title() or text_content() reads once, right now. Assert with expect when the page may still be changing.
    • Writing timeout=5000 out of habit. steero's timeouts are seconds; that waits 83 minutes.
    • Launching without with. If the script fails before browser.close(), the browser keeps running. Use with launch(...) as browser: (or async with steero.launch(...)).
    • Mixing the two APIs. from steero import expect is the async one; in a sync script, import both launch and expect from steero.sync_api.

    Recap¶

    • steero doctor shows which browsers steero can use; steero install chromedriver prepares Chrome ahead of time.
    • A script is launch() a browser, new_page(), goto(), then locators, actions and expect assertions.
    • The sync API (steero.sync_api) and the async API (steero) have the same names; async adds await.
    • Runs are headless by default; headless=False (or STEERO_COURSE_HEADED=1) shows the window.
    • Errors name the action, the locator, the time waited and the reason, so read them first.
